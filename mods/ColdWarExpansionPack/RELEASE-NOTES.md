# Sprocket Cold War Expansion Pack 0.2.0 (core)

Cold War availability and engine/cannon capabilities now follow editable native Era and Technology data. Vehicle dates remain native, engine pricing uses the game's calculation, and the core retains only the final-era maximum-date classification fix.

This core includes the DLL and the native Era/Technology data files. Gameplay addons and the loader are installed separately. On update, keep custom Era/Technology dates and settings; follow the included README rather than overwriting all native data.

Eras (fresh release): the pack now adds three eras of its own, Coldwar1 (from 1945.09.04), Coldwar2 (from 1960.01.01) and Coldwar3 (from 1975.01.01), all playable. It no longer ships or changes the game's own `Eras/Coldwar.json` (the game's placeholder from 1945.09.03, not playable). The DLL is unchanged.

The plugin and config use `sprocket.coldwarexpansionpack`. Optional pack grouping recognizes the Hydropneumatic, Telescopic Mast, Thermal Sight and Smoke Launchers plugins.
