# Sprocket Cold War Expansion Pack 0.2.0 (core)

Cold War availability and engine/cannon capabilities now follow editable native Era and Technology data. Vehicle dates remain native, engine pricing uses the game's calculation, and the core retains only the final-era maximum-date classification fix.

This core includes the DLL and the native Era/Technology data files. Gameplay addons and the loader are installed separately. On update, keep custom Era/Technology dates and settings; follow the included GUIDE.md rather than overwriting all native data.

The plugin and config use `sprocket.coldwarexpansionpack`. Optional pack grouping recognizes the Hydropneumatic, Telescopic Mast, Thermal Sight and Smoke Launchers plugins.
