# Method reference and adapted designer event handoff

The native designer event delegate handoff in CampaignDesignerPlayHook.cs and
scene setup method in CampaignNativeFlow.cs were adapted with reference to
Hans21223/Sprocket-Battle-Editor, v0.18.1, SprocketBattles/NativeDesigner.cs.
https://github.com/Hans21223/Sprocket-Battle-Editor/tree/v0.18.1
The Battle Editor plugin is not a runtime dependency. Its technology-limit
override, faction switching and personal blueprint saving are not included.
