# Reference board model (Phase A)
- OpenSCAD 2021.01; units metres; origin at centre. Board horizontal X, vertical Z, depth Y.
- Image area 2 x 2 m; frame width 0.02 m each side; outer bounds 2.04 x 2.04 m; nominal depth 0.008 m (frame export y approximately +/-0.00399971 due to CGAL).
- At uniform 0.1 and 6 the image area is 0.2 x 0.2 and 12 x 12 m; outer bounds 0.204 and 12.24 m; depth 0.0008 and 0.048 m. Native maximum scale 6 requires live verification.
- Frame is a thin hollow ring, not an opaque backing; the image slab fills the opening, visible from both sides. No backing obscures its rear face.
- `reference-board-frame.stl`: 32 triangles; SHA256 E5131334F96149F0274C2397F6070E653DDA69C8F207459B247B01FCE1F1EC70.
- `reference-board-image.stl`: 12 triangles; SHA256 AC92DF4F4F66BBF48693DF9DE98644A4F1BE793DBEB0C73F1AB27C91AFB344D6.
- Unity mapping: SCAD (x,y,z) -> Unity (x,z,-y), retaining metres and handedness; apply consistently to normals and winding.
- STL has no UVs: in code split/duplicate vertices by face; for both broad faces use u=(SCAD x+1)/2, v=(SCAD z+1)/2, with image vertical convention verified on load. This gives the same projected picture through the slab, mirrored when viewed from behind. Apply Mirror as u -> 1-u on both faces; shade narrow edges with neutral material.
- Preserve aspect by scaling X/Z to match image ratio; nonuniform native scale can otherwise distort it. Runtime material, collider, sizing and scaler behavior require game testing.
- `view-reference-board.scad` imports production STLs; `comparison=0`, `0.1`, or `6`; yellow lines indicate outer bounds. Tank box is 7 x 3.5 x 2.5 m.
- `verify-and-render.ps1` checks committed STL SHA256, re-exports and compares sorted facets (CGAL may reorder facets), renders views and 128x128 transparent icon. Run from PowerShell; requires OpenSCAD at the documented path, Python `py` and System.Drawing.
- Phase B gate: no DLL exists yet; verify embedded mesh data against the current STL geometry/hash during the build, and rerun after any mesh change.
