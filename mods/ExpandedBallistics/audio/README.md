# ATGM launch audio

The launcher and gun-launched recordings embedded in the DLL were created by the author with his own Suno account (the author's statement). The source files were named `BGM-71 Tow launch sound.wav` (launcher) and `ATGM_launch_02_long_impact.wav` (gun-launched). The gun-launched clip was trimmed and level-adjusted during preparation. This release does not change either audio file.

All rights reserved for both code and audio. Optional user PCM16 WAV overrides take priority over embedded clips. Configure `[ATGM Audio] Enabled` and `VolumeMultiplier` in `sprocket.expandedballistics.cfg`; restart after changing settings. Native positional attenuation and mixer handling are retained.
